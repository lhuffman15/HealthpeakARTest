Above: the embed in an <iframe>, sizing itself to its content.

Paste into a WordPress Custom HTML block

<iframe id="hp-portside"
  src="https://healthpeakbayarea.com/availability-embed/?property=portside"
  title="Portside availability: site plan, 3D model and floor plans"
  allow="xr-spatial-tracking; fullscreen"
  loading="lazy"
  style="width:100%;border:0;height:900px"></iframe>
<script>
// Let the embed set its own height (no inner scrollbars)
window.addEventListener('message', function (e) {
  if (e.origin !== location.origin) return;
  if (e.data && e.data.type === 'hp-embed-height') {
    document.getElementById('hp-portside').style.height = e.data.height + 'px';
  }
});
</script>

What changes per property

  1. ?property=portside picks the site plan, 3D model and buildings. Properties without a model just don't show the 3D & AR tab.
  2. Gold buildings come from the data: a building's ON layer in the SVG shows only when it has available floors.
  3. Same-site hosting (the embed living on healthpeakbayarea.com) keeps the height script, AR and analytics simple.
